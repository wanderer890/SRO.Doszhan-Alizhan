# Аналитическая система успеваемости студентов
**Автор:** Досжан Алижан, Группа ТИИ25-21

## Описание
Данный мини-проект реализует аналитическую систему обработки ведомостей, вычисления средних баллов, статусов допуска и формирования рейтинга студентов. Проект разработан в рамках СРО по дисциплине «Парадигмы программирования» и объединяет подходы из первых 8 лекций.

## Запуск проекта
1. Убедитесь, что установлен Python 3.8+
2. Запуск основного приложения (интерфейс в консоли):
   ```bash
   python main.py
   ```
3. Запуск автоматических тестов:
   ```bash
   python test_main.py
   ```

## Архитектура и темы лекций
- **Лекция 1 (Парадигмы):** В `logic.py` и `main.py` реализовано сравнение процедурного, объектно-ориентированного и функционального подходов к расчету среднего балла.
- **Лекция 2 (Императивный прототип):** Консольное меню `while True` с изменяемым состоянием в `main.py`.
- **Лекция 3 (Процедурная декомпозиция):** Функции сгруппированы, выделены явные параметры, реализован процедурный расчет `calculate_average_procedural`.
- **Лекция 4 (Модульность):** Программа разделена на `models.py` (данные), `logic.py` (логика обработки), `main.py` (точка входа) и `test_main.py` (тесты).
- **Лекция 5 (ООП, Классы):** Сущности `Student`, `GradeBook` с инкапсуляцией списка студентов.
- **Лекция 6 (Полиморфизм, Интерфейсы):** Интерфейс `GradingPolicy` с двумя взаимозаменяемыми реализациями (`WeightedPolicy` и `BestAttemptPolicy`).
- **Лекция 7 (Функциональная парадигма):** Использование чистых функций `calculate_average_functional`, не изменяющих состояние входных коллекций. Применение `reduce` для сбора оценок.
- **Лекция 8 (Функции высшего порядка, ленивые вычисления):** Конвейер с использованием `map` и `filter`, генератор строк отчета `report_generator`, применение замыканий в функции фильтрации.

## Данные
Генерируется набор из 20 студентов с оценками по 3 дисциплинам, что полностью соответствует требованиям СРО.
